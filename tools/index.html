Tools

Tools marked in your browser run entirely on your device — nothing is sent anywhere. Tools marked server lookup send the hostname to our server for a bounded public DNS or HTTPS lookup.

JWT decoder

Inspect headers and claims; signatures are not verified.

in your browser

CIDR / subnet calculator

Calculate IPv4 network boundaries, masks and usable addresses.

in your browser

Password generator

Generate random passwords with your browser’s cryptographic random source. The length must be 12–128 characters.

in your browser

Base64 encoder / decoder

Encode and decode UTF-8 text. Base64 is encoding, not encryption.

in your browser

Text hash calculator

Calculate a SHA-256, SHA-384 or SHA-512 digest locally. A plain hash is not password storage.

in your browser

Cron field explainer

Validate and describe standard numeric five-field cron expressions.

in your browser

MikroTik address-list helper

Generate a reviewable RouterOS address-list command. This does not change your router or firewall rules.

in your browser

DNS lookup

Read a public IPv4 DNS answer from one resolver. This is not a worldwide propagation test.

server lookup

HTTPS header check

Check common response-header presence on the HTTPS root page. Redirects are not followed; presence alone does not prove a secure configuration.

server lookup

Email authentication

Discover SPF, DMARC, MX and MTA-STS DNS records.

server lookup

TLS inspector

Inspect a verified HTTPS certificate and connection.

server lookup
