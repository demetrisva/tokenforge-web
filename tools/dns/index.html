Tools / DNS lookup

DNS lookup

Look up A, AAAA, MX, TXT, NS, CNAME, SOA, CAA and reverse DNS records.

Results come from one recursive resolver. This is not an authoritative lookup or a worldwide propagation test.

Enter a DNS name without a URL, path or port. TXT accepts service labels such as _dmarc.example.com.

Your query is sent to our lookup API and DNS resolver. Do not submit secrets or private names.

Related checks

MX lookup with mail-server addresses · SPF, DMARC and MTA-STS · TLS inspector

These tools discover records; they do not verify email delivery, test SMTP or check blocklists. MX record TTL is unavailable; address TTL is shown where returned.
