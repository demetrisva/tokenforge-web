Free security & network tools that respect your privacy.

A small, honest toolbox for admins and developers. Browser-only tools never send your input anywhere. Public DNS and HTTPS lookup tools run on our server.

Tools

JWT decoder

Inspect headers and claims; signatures are not verified.

in your browser

CIDR / subnet calculator

Calculate IPv4 network boundaries, masks and usable addresses.

in your browser

Password generator

Generate random passwords with your browser’s cryptographic random source. The length must be 12–128 characters.

in your browser

Base64 encoder / decoder

Encode and decode UTF-8 text. Base64 is encoding, not encryption.

in your browser

Text hash calculator

Calculate a SHA-256, SHA-384 or SHA-512 digest locally. A plain hash is not password storage.

in your browser

Cron field explainer

Validate and describe standard numeric five-field cron expressions.

in your browser

MikroTik address-list helper

Generate a reviewable RouterOS address-list command. This does not change your router or firewall rules.

in your browser

MX lookup

Find mail servers by priority and expand their IPv4 and IPv6 addresses.

server lookup

DNS lookup

Query common DNS record types and reverse DNS from one resolver.

server lookup

HTTPS header check

Check common response-header presence on the HTTPS root page. Redirects are not followed; presence alone does not prove a secure configuration.

server lookup

Email authentication

Discover SPF, DMARC, MX and MTA-STS DNS records.

server lookup

TLS inspector

Inspect a verified HTTPS certificate and connection.

server lookup

JSON formatter

Validate, pretty-print or minify JSON. Large integers may lose precision when parsed as JavaScript numbers.

in your browser

URL component encoder

Encode or decode a URL component using UTF-8 percent encoding. This does not parse a complete URL or treat + as a space.

in your browser

UUID v4 generator

Generate 1–100 random UUIDs with your browser’s cryptographic random source.

in your browser

Unix timestamp converter

Convert seconds or milliseconds to UTC, or an ISO timestamp with an explicit timezone to Unix time.

in your browser

Text / hex converter

Convert UTF-8 text to hexadecimal bytes or decode valid UTF-8 hex.

in your browser

IPv4 range to CIDR

Split an inclusive IPv4 address range into the smallest exact set of CIDR blocks.

in your browser
