Tools

A small, inspectable toolbox

TokenForge is an independent collection of utilities for administrators and developers.

Local tools

JWT decoding, CIDR calculations, random password generation, UTF-8 Base64, text hashes, cron descriptions the RouterOS helper, JSON formatting, URL component encoding, UUID v4 generation, Unix timestamps, UTF-8 hex and IPv4 range summarisation run in your browser. Input is not sent to our API. JWT signatures are not verified. Passwords use the browser’s cryptographic random source.

JSON uses JavaScript numbers, so large integer precision is not preserved. Timestamp date input requires an explicit timezone. URL encoding operates on a component, not a complete URL. Hex decoding accepts valid UTF-8 only.

Public lookups

Email authentication checks discover DNS records, rather than fully evaluating mail delivery. DNS results come from a single resolver. TLS inspections verify the certificate and hostname; they are not an exhaustive protocol or cipher audit. Header checks inspect the HTTPS root response and do not follow redirects. None of these results is a security certification.

Privacy

Lookup hostnames are sent to our API and to the DNS/HTTPS services needed to answer them. The application does not write lookup inputs to logs or a database. Cloudflare and hosting providers may process request and connection metadata. Do not submit secrets or private hostnames.

Architecture

The static website is served by Cloudflare Workers static assets. A separate container on our VPS handles bounded DNS and HTTPS requests over Cloudflare Tunnel. Administrative services and the private assessment scanner are accessed through Tailscale, outside this public toolbox.
